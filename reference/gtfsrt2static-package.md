# gtfsrt2static: Realized Static GTFS Snapshots from GTFS-Realtime and GPS-Derived Observations

Converts archived GTFS-Realtime feeds ('Trip Updates', 'Vehicle
Positions') and GPS-derived observations into standard-compliant static
GTFS snapshots that describe public transit service as actually
operated. Provides a canonical observed-stop-events table that both
input paths converge on, an assembler that merges observations into a
baseline static feed or scaffolds a compliant feed from scratch, and a
lightweight collector for continuously archiving ephemeral GTFS-Realtime
endpoints.
